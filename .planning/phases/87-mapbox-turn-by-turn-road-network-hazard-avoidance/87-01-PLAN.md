### WP3: Deterministic Tangential Avoidance Waypoint Engine (`frontend/lib/aiDynamicRouter.ts`)
1. **Vector Orthogonality & Clearance Math:**
   - For origin $O(x_o, y_o)$, destination $D(x_d, y_d)$, and hazard center $H(x_h, y_h)$:
     * Calculate corridor direction vector: $OD = (x_d - x_o, y_d - y_o)$.
     * Calculate unit normal vectors perpendicular to corridor:
       $$N_1 = \left(-\frac{y_d - y_o}{\|OD\|}, \frac{x_d - x_o}{\|OD\|}\right), \quad N_2 = \left(\frac{y_d - y_o}{\|OD\|}, -\frac{x_d - x_o}{\|OD\|}\right)$$
     * Set clearance radius: $d_{\text{clearance}} = R_{\text{hazard}} + 2.0\text{ km}$ (calibrated tightly for urban corridors, replacing outdated $+6.0\text{ km}$).
     * Compute tangential avoidance waypoints:
       $$W_{\text{tangent}} = H + N \times d_{\text{clearance}}$$
2. **Multi-Angle Candidate Exploration:**
   - Evaluate bilateral tangential angles: $+90^\circ$ and $-90^\circ$.
   - If both produce obstruction, evaluate diagonal flanking vectors at $\pm 45^\circ$.
   - Format 3-stop waypoints: `${origin};${waypoint};${destination}`.
3. **Hazard Exposure Verification:**
