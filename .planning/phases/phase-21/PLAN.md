## Root Cause Diagnosis (Pre-Execution Findings)

### Why rectangular boxes always appear:

1. **`weather_fusion_service.py` — 4 hardcoded rectangular polygons**
   `NORTH_SUMATRA_REGIONAL_BOUNDARIES` is a Python list of 4 rectangular `[lon, lat]` bounding boxes hardcoded in the service. BMKG and Earth-2 APIs are called but only affect the fill color — the shape is always a box. This is the primary source of the "4 rectangular zones" visible in PRESENT mode.

2. **`historical_episodes.json` fixture — rectangular fallback geometry**
   When Supabase `ltm_episodes` table is unavailable (no credentials or empty), the `/incidents/historical/episodes` endpoint reads from the fixture file. The `geojson_geometry` field in that fixture contains rectangular coordinate arrays (e.g., `[98.68, 3.58], [98.88, 3.58], [98.92, 3.38]...`), not flood contours or seismic polygons.

3. **`disasterZones` never fetched from backend**
   In `DashboardClient.tsx`, `disasterZones` prop passed to `CrisisMap` is never populated from an API call — it's an empty array by default. The `disaster-zones-fill` Mapbox layer exists on the canvas but contains no features.

4. **`historicalEpisodes` / `predictiveRisks` only fetched on initial load, not on mode switch**
   The frontend does not re-fetch these datasets when `activeTimeFilter` changes from `present` → `past` or `future`. The data is either stale or empty when switching modes.

5. **OSINT worker not started in Docker container**
   `osint_worker.py` exists with `PIHPSScraper`, `MarketplaceScraper`, and `SocialScraper` — but `main.py` has no `asyncio.create_task()` call for any background adapter at startup. No live OSINT data enters Redis Streams unless the worker is manually invoked externally.

### DELIVERABLE 1 — Organic Incident Geometry Service (Backend)

**File:** `backend/app/services/incident_geometry_service.py` [NEW]

Generate algorithmically correct, visually distinct GeoJSON geometries per hazard type. No external DEM API needed for MVP — uses spatial math only.

**Per hazard type:**

| Hazard | Geometry Output | Visual Character |
|---|---|---|
| `earthquake` | Concentric shockwave `MultiPolygon` rings (epicenter, 3 radius bands) + `LineString` fault crack vectors at BMKG strike angle | Radiating rings + crack lines |
| `flood` | River-following `Polygon` (elongated along N-S valley axis, wider at low elevation) derived from centroid + affected corridors metadata | Organic blob, not rectangle |
| `landslide` | Wedge `Polygon` — narrow at top (slide source), wide at bottom (debris fan) | Triangular wedge downslope |
| `wildfire` | Wind-skewed ellipse `Polygon` — elongated in prevailing wind direction | Asymmetric oval |
| `congestion` | `LineString` along highway spine with buffer offset | Corridor line, not zone |

**API surface:**
```python
def generate_incident_geometry(
    hazard_type: str,
    lat: float,
    lon: float,
    magnitude: float = 5.0,
    radius_km: float = 15.0,
    bearing_deg: float = 150.0,  # BMKG fault strike
    water_depth_m: float = 1.0,
    wind_bearing_deg: float = 270.0,
) -> dict  # Returns GeoJSON Feature
```

### DELIVERABLE 3 — BMKG Background Polling at Startup

**File:** `backend/app/main.py` [MODIFY]

Add background task to `lifespan()` context manager so BMKG earthquakes and weather warnings are polled without a separate container:

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # Start background BMKG polling (fire-and-forget)
    async def _poll_bmkg_loop():
        from app.adapters.bmkg_adapter import BMKGAdapter
        adapter = BMKGAdapter()
        while True:
            try:
                raw = await adapter.fetch()
                events = await adapter.parse(raw)
                for ev in events:
                    # Store in Redis STM for /incidents/osint/live endpoint
                    r = get_redis()
                    r.lpush("lrip:live_events", json.dumps(ev))
                    r.ltrim("lrip:live_events", 0, 49)  # Keep last 50
            except Exception as e:
                logger.warning(f"BMKG poll error: {e}")
            await asyncio.sleep(60)
    
    task = asyncio.create_task(_poll_bmkg_loop())
    yield
    task.cancel()
```

### DELIVERABLE 4 — Live OSINT Endpoint + Mock Fallback

**File:** `backend/app/routers/incidents.py` [MODIFY]

Add endpoint `GET /incidents/osint/live` that reads from Redis `lrip:live_events` list and returns the last N events with geometry attached:

```python
@router.get("/osint/live")
async def get_live_osint():
    """Returns latest BMKG+OSINT events from Redis STM (last 50, enriched with geometry)."""
    r = get_redis()
    raw_events = r.lrange("lrip:live_events", 0, 19)  # Last 20
    events = []
    for raw in raw_events:
        ev = json.loads(raw)
        # Enrich with geometry
        from app.services.incident_geometry_service import generate_incident_geometry
        geom = generate_incident_geometry(
            hazard_type=ev.get("event_type", "flood"),
            lat=float(ev.get("lat", 3.58)),
            lon=float(ev.get("lon", 98.67)),
        )
        ev["geojson_geometry"] = geom
        events.append(ev)
    
    # Fallback to MOCK_SOCIAL_POSTS enriched if Redis empty
    if not events:
        events = _get_mock_live_events()
    
    return {"items": events, "total": len(events), "source": "redis_stm"}
```

### DELIVERABLE 5 — Frontend: Mode-Aware Data Fetching

**File:** `frontend/components/dashboard/DashboardClient.tsx` [MODIFY]

Add `useEffect` that re-fetches the correct dataset each time `activeTimeFilter` changes:

```typescript
// Fetch mode-specific data when time filter changes
useEffect(() => {
  const fetchModeData = async () => {
    setIsLoadingModeData(true);
    try {
      if (activeTimeFilter === 'past') {
        const res = await fetch('/api/v1/incidents/historical/episodes');
        const data = await res.json();
        setHistoricalEpisodes(data.items || []);
      } else if (activeTimeFilter === 'future') {
        const res = await fetch('/api/v1/incidents/predictive/risks');
        const data = await res.json();
        setPredictiveRisks(data.items || []);
      } else if (activeTimeFilter === 'predict') {
        const res = await fetch('/api/v1/incidents/predictive/risks');
        const data = await res.json();
        setEconomicCascades(data.items || []);
      }
    } catch (e) {
      console.error('Mode data fetch failed:', e);
    } finally {
      setIsLoadingModeData(false);
    }
  };
  fetchModeData();
}, [activeTimeFilter]);
```

Also fetch `disasterZones` from `/api/v1/incidents` filtered by `status=validated` and map to `DisasterZone` type with `geojson_geometry` geometry.
