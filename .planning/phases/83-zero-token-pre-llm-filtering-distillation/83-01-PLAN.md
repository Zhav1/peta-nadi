## 2. Decision Constraints (Non-Negotiable)

1. **Zero External Dependencies:**
   - Use Python standard library (`re`, `html`, `urllib.parse`) only.
   - Do NOT install heavy packages like `readability-lxml`, `trafilatura`, or `beautifulsoup4`.
2. **Two-Factor Deterministic Regex Gating:**
   - An article MUST match at least one Disaster Keyword AND at least one Sumatra Geographic Anchor.
   - Articles failing this check MUST drop immediately as `DROPPED_IRRELEVANT` with **0 tokens expended**.
3. **Strict Text Clamping:**
   - Headline: max 120 characters.
   - Lead body text: max 400 characters.
   - Total prompt budget per article candidate: $< 150\text{ tokens}$ ($>80\%$ reduction from previous 1,600 chars).
4. **Compact Single-Shot JSON Output Schema:**
   - Strict output schema:
     ```json
     {
       "is_disaster": boolean,
       "type": string,
       "location": string,
       "confidence": number
     }
     ```
   - No narrative conversational headers (`=== HASIL ===`, "Berdasarkan analisis...").
5. **Universal `<think>` Trace Stripping:**
   - All completions passing through `LLMGateway` must have `<think>...</think>` blocks purged before JSON deserialization.
6. **Backward Compatibility:**
   - Existing caller contracts in `unified_news_ingestor.py` and `news_router.py` must remain intact.

## 3. Work Packages & Implementation Tasks

### WP1: Clean DOM & Boilerplate Stripper (`news_aggregator.py`)
- **File:** `backend/app/services/news_aggregator.py`
- **Function:** `extract_lead_text_from_html(html: str) -> str`
- **Logic:**
  1. Strip `<script>`, `<style>`, `<nav>`, `<footer>`, `<aside>`, `<header>`, `<form>`, `<svg>`, `<iframe>`.
  2. Strip elements matching ad/widget classes: `(?:ad|advertisement|sidebar|widget|promo|banner|comment|share)`.
  3. Extract OpenGraph description (`og:description`) or meta description as primary candidate.
  4. Collect first 2 `<p>` tags within `<article>` or `.entry-content` / `.detail__body-text`.
  5. Filter paragraphs: reject items $<40$ chars or containing blacklist phrases (`"baca juga"`, `"advertisement"`, `"infotorial"`, `"iklan"`, `"editor:"`, `"pewarta:"`, `"copyright"`).
  6. Clamp total returned lead text to **400 characters**.

### WP2: Two-Factor Disaster & Sumatra Geography Regex Gate (`news_extractor.py`)
- **File:** `backend/app/nlp/news_extractor.py`
- **New Function:** `passes_disaster_regex_gate(title: str, text: str) -> bool`
- **Regex Predicates:**
  - **Disaster Predicate:**
    ```python
    DISASTER_PATTERN = re.compile(
        r'\b(banjir|longsor|tanah amblas|jalan putus|jembatan putus|gempa|tektonik|'
        r'erupsi|gunung meletus|gelombang tinggi|ombak besar|abrasi|karhutla|kebakaran hutan|'
        r'truk terguling|kemacetan parah|pelabuhan tutup|dermaga tutup|akses lumpuh)\b',
        re.IGNORECASE
    )
    ```
  - **Sumatra Geography Predicate:**
    ```python
    SUMATRA_GEO_PATTERN = re.compile(
        r'\b(sumatera|sumut|sumbar|aceh|riau|jambi|sumsel|bengkulu|lampung|'
        r'medan|belawan|tebing tinggi|asahan|deli serdang|langkat|sitinjau|'
        r'padang|bukittinggi|solok|agam|pasaman|pekanbaru|dumai|kampar|siak|'
        r'palembang|banyuasin|ogan|lahat|lampung|bakauheni|bandar lampung)\b',
        re.IGNORECASE
    )
    ```
- **Rule:** If `not passes_disaster_regex_gate(title, text)`:
  - Immediately return baseline with `zone_tier="DROPPED_IRRELEVANT"` and `tier_reason="Regex gate: bukan bencana atau di luar koridor Sumatera"`.
  - Never add to LLM batch candidates.

### WP3: Text Clamping & Distillation Engine (`news_extractor.py`)

### WP4: Compact DeepSeek JSON Prompt & `<think>` Stripper
- **Files:** `agents/llm_gateway.py` & `backend/app/nlp/news_extractor.py`
- **Prompt Specification:**
  ```text
  Klasifikasikan artikel berita logistik Sumatera berikut.
  Kembalikan HANYA array JSON (tanpa markdown, tanpa penjelasan, tanpa tag think):
  [
    {
      "id": "string",
      "is_disaster": true|false,
      "type": "flood"|"landslide"|"earthquake"|"wildfire"|"port_closure"|"road_closure"|"congestion"|"other",
      "location": "string nama kabupaten/kota/jalan di Sumatera",
      "confidence": 0.0-1.0
    }
  ]
  Aturan: is_disaster=true HANYA untuk bencana fisik aktif yang mengganggu logistik. Opini, seminar, dan perbaikan pascabencana adalah false.
  ```
- **Tag Stripper in `llm_gateway.py`:**
  ```python
  def strip_thinking_tags(text: str) -> str:
      """Removes <think>...</think> chain-of-thought blocks from reasoning models."""
      return re.sub(r'<think>.*?</think>', '', text, flags=re.DOTALL).strip()
  ```
  - Apply `strip_thinking_tags` on completion text before returning from `LLMGateway.generate_content`.
