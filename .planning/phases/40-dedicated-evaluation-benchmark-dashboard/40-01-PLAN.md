# Plan 40-01: Backend Evaluation Endpoints, Test Data Synchronization & Automated Test Suite

<objective>
Build the backend API foundation and schema contracts for PreHub's Dedicated Evaluation & Benchmark Dashboard. Implement FastAPI endpoints serving empirical benchmark data ($N=60$ Sumatra scenarios, precision, recall, F1, Brier score, 10-bin calibration distribution), the exhaustive 81-test verification matrix (FR-1 through FR-13), and corridor routing efficiency metrics. Provide automated test coverage and synchronized frontend TypeScript interfaces with resilient offline fallback.

Purpose: Provide grounded, API-accessible verification data to back every empirical claim made in the dashboard and technical defense.
Output: Pydantic schemas, FastAPI router, router registration in main.py, automated pytest suite, and frontend API client methods.
</objective>

  <name>Task 1: Create Pydantic v2 Evaluation Schemas</name>
  <files>backend/app/schemas/evaluation.py</files>
  <read_first>
    - test-results/benchmark_evaluation_report.json
    - docs/test_matrix.md
    - .planning/phases/40-dedicated-evaluation-benchmark-dashboard/40-UI-SPEC.md
  </read_first>
  <action>
    Create `backend/app/schemas/evaluation.py` defining:
    - Model `ConfusionMatrix`: `true_positives: int`, `false_positives: int`, `true_negatives: int`, `false_negatives: int`.
    - Model `EvaluationMetrics`: `precision: float`, `recall: float`, `f1_score: float`, `false_positive_rate: float`, `accuracy: float`, `mean_latency_ms: float`, `total_latency_ms: float`.
    - Model `ReliabilityBinItem`: `bin_index: int`, `range: List[float]`, `sample_count: int`, `mean_confidence: float`, `empirical_accuracy: float`, `calibration_error: float`.
    - Model `CalibrationReport`: `brier_score: float`, `expected_calibration_error: float`, `platt_calibrated_brier: float`, `isotonic_calibrated_brier: float`, `reliability_bins: List[ReliabilityBinItem]`.
    - Model `BenchmarkThresholds`: `min_precision: float`, `min_recall: float`, `min_f1: float`, `max_brier_score: float`.
    - Model `BenchmarkReportResponse`: `status: str = "success"`, `timestamp: str`, `total_scenarios: int`, `confusion_matrix: ConfusionMatrix`, `metrics: EvaluationMetrics`, `calibration: CalibrationReport`, `thresholds: BenchmarkThresholds`, `gating_passed: bool`.
    - Model `TestCaseItem`: `test_id: str`, `fr_id: str`, `category: str`, `module: str`, `test_type: str`, `scenario: str`, `expected_invariant: str`, `result: str = "Passed"`, `execution_time_ms: Optional[float] = None`.
    - Model `TestMatrixResponse`: `status: str = "success"`, `total_tests: int`, `passed_tests: int`, `failed_tests: int`, `fr_domain_counts: Dict[str, int]`, `tests: List[TestCaseItem]`.
    - Model `CorridorEfficiencyItem`: `corridor_name: str`, `origin: str`, `destination: str`, `modality: str`, `baseline_distance_km: float`, `blocked_delay_hours: float`, `reroute_distance_km: float`, `reroute_delay_minutes: float`, `time_saved_hours: float`, `fuel_saved_liters: float`, `cost_saved_idr: int`, `solver_latency_ms: float`.
    - Model `CorridorEfficiencyResponse`: `status: str = "success"`, `corridors: List[CorridorEfficiencyItem]`, `total_cost_saved_idr: int`, `avg_time_saved_hours: float`.
  </action>
  <verify>
    Verify with python: `backend/.venv/Scripts/python.exe -c "from app.schemas.evaluation import BenchmarkReportResponse, TestMatrixResponse, CorridorEfficiencyResponse; print('Schemas OK')"`
  </verify>
</task>

<task type="auto" id="40-01-02">
  <name>Task 2: Implement Evaluation FastAPI Router & Register in Main</name>
  <files>backend/app/routers/evaluation_router.py, backend/app/main.py</files>
  <read_first>
    - backend/app/schemas/evaluation.py
    - test-results/benchmark_evaluation_report.json
    - docs/test_matrix.md
    - backend/app/main.py
  </read_first>
  <action>
    1. Create `backend/app/routers/evaluation_router.py` with prefix `"/evaluation"`:
       - `GET /benchmark` -> returns `BenchmarkReportResponse`.
         - Reads `test-results/benchmark_evaluation_report.json` if available.
         - If unavailable, provides deterministic fallback matching verified Phase 36/37 empirical results (Precision=1.0, Recall=0.9714, F1=0.9855, Brier=0.0782, Latency=0.019 ms, 10 bins).
       - `GET /test-matrix` -> returns `TestMatrixResponse`.
         - Parses or structured-serves the 81 automated tests from `docs/test_matrix.md` (FR-1 to FR-13).
         - Supports optional query parameters: `fr_id: Optional[str] = None`, `search: Optional[str] = None`.
       - `GET /corridor-efficiency` -> returns `CorridorEfficiencyResponse`.
         - Returns comparison data for key corridors (e.g. Belawan-Medan-Tebing Tinggi, Padang-Bukittinggi Sitinjau Lauik, Palembang-Betung KM 68) showing hours saved, fuel saved, cost savings, and CPU Dijkstra latency.
    2. Register the router in `backend/app/main.py`:
       - Import `evaluation_router` from `app.routers`.
       - Add `app.include_router(evaluation_router.router, prefix="/api/v1")`.
  </action>
  <verify>
    Verify FastAPI routes: `backend/.venv/Scripts/python.exe -c "from app.main import app; print([r.path for r in app.routes if 'evaluation' in r.path])"`
  </verify>
</task>
