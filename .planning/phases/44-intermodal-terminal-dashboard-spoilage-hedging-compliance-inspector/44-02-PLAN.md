## 2. Technical Scope & Implementation Steps

### Task 1: TypeScript Types & API Client Integration (`frontend/lib/types.ts` & `frontend/lib/api.ts`)
- Update `frontend/lib/types.ts`:
  - Add `ChokePointItem`, `ChokePointsListResponse`.
  - Add `HedgingSolveRequest`, `PolicyBreakdown`, `HedgingSolveResponse`.
  - Add `ComplianceVerifyRequest`, `ComplianceCheckDetail`, `ComplianceVerifyResponse`.
- Update `frontend/lib/api.ts`:
  - Add `api.intermodal`:
    - `getChokePoints(): Promise<ChokePointsListResponse>`
    - `getChokePoint(id: string): Promise<ChokePointItem>`
    - `solveHedging(req: HedgingSolveRequest): Promise<HedgingSolveResponse>`
    - `verifyCompliance(req: ComplianceVerifyRequest): Promise<ComplianceVerifyResponse>`
    - `getTollTariffs(): Promise<Record<string, any>>`

### Task 2: React Data Hook (`frontend/hooks/useIntermodalData.ts`)
- Create custom React hook:
  - Fetches choke-points from `/api/v1/intermodal/chokepoints` with polling / refresh.
  - Exposes `calculateHedging(params)` helper for rapid re-calculation upon route selection.
  - Exposes `checkCompliance(params)` helper for active vehicle verification.
  - Provides robust mock fallbacks if the backend server is temporarily starting up.

### Task 3: Spoilage Hedging Card (`frontend/components/sidebar/SpoilageHedgingCard.tsx`)
- Build glassmorphic container:
  - Header with `DollarSign` and `ThermometerSnowflake` icons, commodity name, and perishability decay tier.
  - 3-Column Policy Matrix:
    - **CONTINUE**: Monetary risk exposure + cargo loss + driver downtime.
    - **REROUTE**: Detour distance fuel + BPJT toll + driver overtime.
    - **HOLD**: Staging parking fee + cold-chain reefer diesel genset cost.
  - Optimal policy card marked with Emerald border and glowing "Rekomendasi Hemat" badge.
  - "Terapkan Kebijakan Mitigasi" action button that selects the route or dispatches maneuver.

### Task 4: Digital Compliance Inspector Card (`frontend/components/sidebar/ComplianceInspectorCard.tsx`)
- Build glassmorphic checklist component:
  - Header with `Scale` and `Shield` icons and Surat Jalan Delivery Order verification status.
  - Check item 1: **Karantina Pertanian (BKHIT)** — Green check if intra-island or certified; Red shield with Hard Block message if inter-island without certificate.
  - Check item 2: **Muatan Sumbu Terberat (MST)** — Green if within road class limit; Amber alert badge if >8 Ton on Class III road with detour advisory.
  - Check item 3: **Integritas Manifest & Sopir** — Verified driver phone and vehicle plate hash.
  - Operator override button for MST advisory with confirmation toast.

### Task 5: Intermodal Terminal Popover (`frontend/components/dashboard/IntermodalTerminalPopover.tsx`)
- Build top navigation popover:
  - Trigger pill: `[ Ship Icon | INTERMODAL: 18 Hub ]` in `TopNavTelemetry.tsx`.
  - Dropdown content:
    - Section A: **Pelabuhan & Terminal Penyeberangan (7 Hubs)**: Belawan, Bakauheni, Dumai, Teluk Bayur, Panjang, Sibolga, Kuala Tanjung. Displays dwell time and $M_{\text{intermodal}}$.
    - Section B: **Titik Rawan Tanjakan & Persimpangan (11 Hubs)**: Sitinjau Lauik, Kelok 9, Malalak, Tarutung-Sibolga, Tebing Tinggi, Betung, etc. Displays road status and hazard classification.
  - Smooth animation on open/close with click-outside listener.

### Task 6: Sidebar & Top Navigation Assembly
- In `frontend/components/sidebar/MitigationTab.tsx`:
  - Mount `SpoilageHedgingCard` above or adjacent to route recommendations.
  - Mount `ComplianceInspectorCard` below route details.
- In `frontend/components/dashboard/TopNavTelemetry.tsx`:
  - Add the `IntermodalTerminalPopover` button to the telemetry bar.
- In `frontend/components/dashboard/DashboardClient.tsx`:
  - Pass active vehicle, selected route, and corridor context to `MitigationTab`.
