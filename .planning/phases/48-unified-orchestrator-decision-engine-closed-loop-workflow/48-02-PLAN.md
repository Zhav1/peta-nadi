# Plan 48-02: Agent 4 & 6 Decision Engines Integration (Spoilage Hedging, Compliance & Choke-Points)

## 1. Objective
Embed the defense-grade decision engines developed in Phase 44 directly into the LangGraph swarm:
- [spoilage_hedging_service.py](file:///d:/College/Pidi.id/backend/app/services/spoilage_hedging_service.py) (Continue vs Reroute vs Hold monetary calculations)
- [compliance_service.py](file:///d:/College/Pidi.id/backend/app/services/compliance_service.py) (BKHIT quarantine hard-block and MST axle-load warnings)
- [intermodal_sync_service.py](file:///d:/College/Pidi.id/backend/app/services/intermodal_sync_service.py) (18+ choke-point delay multiplier)

Ensure Agent 4 calculates these metrics for candidate routes, and Agent 6 synthesizes an explainable, Globot-grade decision card comparing policy costs.

---

## 2. Target Files & Key Modifications

### 1. `agents/nodes/route_optimization.py` (Agent 4)
- Import `calculate_operational_spoilage_hedging` from `app.services.spoilage_hedging_service`.
- Import `ComplianceService` from `app.services.compliance_service`.
- Import `IntermodalSyncService` from `app.services.intermodal_sync_service`.
- During corridor candidate generation:
  - Check proximity to any choke-point ($\le 25\text{km}$) and apply delay multiplier $M \in [1.0, 3.5]$.
  - Run `ComplianceService.verify_route()` with cargo manifest info (if present in state) or default perishable cargo:
    - Flag `HARD_BLOCK` if inter-island corridor lacks BKHIT certificate.
    - Flag `TACTICAL_WARNING` if heavy truck traverses Class III road (e.g. Sitinjau Lauik).
  - Run `calculate_operational_spoilage_hedging()`:
    - Compare monetary cost of Continue (decay loss) vs Reroute (toll + fuel) vs Hold (genset diesel).
  - Attach `hedging_summary` and `compliance_status` to candidate routes and `route_optimization_finding`.

### 2. `agents/nodes/decision_support.py` (Agent 6)
- Update evidence payload to include `hedging_breakdown`, `compliance_status`, and `chokepoint_delay_factor`.
- Update prompt and default fallback generator to state the exact monetary trade-off:
  - e.g.: *"REKOMENDASI TAKTIS (EXPLAINABLE AI): Alihkan via Tol Medan-Kualanamu-Tebing Tinggi (Tol MKTT). Kebijakan REROUTE menghemat Rp 42.500.000 dibandingkan membiarkan kargo pangan membusuk (CONTINUE: kerugian Rp 68.200.000), dengan tambahan biaya tol/BBM sebesar Rp 2.850.000. Sertifikat Karantina BKHIT valid."*
