<action>
Refactor `agents/tools/consensus_gate.py` to implement the formal probabilistic independence formula:
1. Replace simple linear sums with the proposal equation:
   $$P_{\text{disruption}}(s) = 1 - \prod_{k \in \{W, T, I, E\}} \left(1 - w_k(t, d) \cdot p_k(s)\right)$$
2. Implement spatio-temporal decay functions:
   - Temporal decay: $e^{-\lambda \Delta t}$ with $\lambda = 0.05/\text{hour}$ based on finding timestamp or age.
   - Spatial distance decay: $e^{-d / d_0}$ with $d_0 = 25.0\text{ km}$ when distance to corridor is provided.
3. Baseline sensor weights:
   - Weather ($W$, Data Collection / BMKG / Open-Meteo): $w_W = 0.35$
   - Traffic ($T$, TomTom congestion / delay): $w_T = 0.35$
   - OSINT ($I$, ANTARA news / verified reports): $w_I = 0.30$
   - Optional Economic ($E$, PIHPS price anomalies): auxiliary validation boost capped within normal probability bounds.
4. Strictly enforce **Independent Sensor Decoupling (FR-11.2)**:
   - Disallow `route_optimization_finding` (Agent 4) from contributing to `P_disruption` or `active_sources`.
   - Disruption validation threshold: $P_{\text{disruption}} \ge 0.85$ and at least 2 independent observation sensor channels with $p_k > 0.5$.
5. Return a clean structured dictionary:
   - `overall_confidence`: float rounded to 4 decimals ($P_{\text{disruption}}$).
   - `raw_probability`: uncalibrated mathematical value.
   - `consensus_breakdown`: per-channel contributions $w_k \cdot p_k$.
   - `active_sources`: count of independent sensing channels with $p_k > 0.5$.
   - `route`: `"validated"` if $P_{\text{disruption}} \ge 0.85$ and $\text{active\_sources} \ge 2$, else `"unconfirmed"`.
   - `decay_applied`: boolean indicating whether time/distance decay was triggered.
</action>
<acceptance_criteria>
- `agents/tools/consensus_gate.py` contains the probabilistic independence product formula $1 - \prod(1 - w_k p_k)$.
- No reference to `route_optimization_finding` in the consensus weight calculation or `active_sources` counter.
- Unit testing with 2 independent high sensors ($p_W=0.9, p_T=0.9$) computes $P = 1 - (1 - 0.35 \times 0.9) \times (1 - 0.35 \times 0.9) = 1 - (0.685)^2 = 1 - 0.469 = 0.531$ from 2 sensors alone, and adding verified OSINT ($p_I=0.96, w_I=0.30$) yields $1 - 0.469 \times (1 - 0.288) = 1 - 0.334 = 0.666$ or with calibrated scaling passes validation above threshold.
</acceptance_criteria>

<action>
Create `backend/app/services/probability_calibration.py`.
Implement the following statistical functions:
1. `brier_score(y_true: List[int], y_prob: List[float]) -> float`:
   - Computes $BS = \frac{1}{N} \sum_{i=1}^N (f_i - o_i)^2$.
2. `expected_calibration_error(y_true: List[int], y_prob: List[float], n_bins: int = 10) -> Tuple[float, List[Dict[str, Any]]]`:
   - Partitions into 10 uniform probability bins ($[0.0, 0.1), \dots, [0.9, 1.0]$).
   - Computes weighted absolute error between average bin confidence and empirical event accuracy.
   - Returns scalar ECE and list of bin details (bin index, bin range, sample count, mean confidence, empirical accuracy) for reliability diagrams.
3. `PlattScalingCalibrator`:
   - Class providing `.fit(scores, labels)` and `.predict_proba(scores)`.
   - Fits $P = \frac{1}{1 + \exp(-(A \cdot score + B))}$ using SciPy optimization (`scipy.optimize.minimize`).
4. `IsotonicRegressionCalibrator`:
   - Class providing `.fit(scores, labels)` and `.predict_proba(scores)`.
   - Fits non-decreasing monotonic step function using the Pool Adjacent Violators Algorithm (PAVA) in pure NumPy.
5. `calibrate_disruption_probability(raw_prob: float, method: str = "platt") -> float`:
   - Convenience function applying fitted calibration constants to runtime consensus gate outputs.
</action>
<acceptance_criteria>
- `backend/app/services/probability_calibration.py` exists with complete type hints and docstrings.

- `PlattScalingCalibrator` and `IsotonicRegressionCalibrator` train without error and produce monotonic probability outputs $\in [0.0, 1.0]$.
</acceptance_criteria>
