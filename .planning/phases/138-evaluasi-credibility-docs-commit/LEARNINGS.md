## 2. Concerns (open, evidenced)

1. **Benchmark is 100% circular-synthetic**: N=60 rows are generated by the same
   heuristic the benchmark then scores — precision/recall measure self-agreement,
   not real-world skill.
2. **P_max 0.688, pass margin 0.0063**: the ECONOMIC_ACTIVE ceiling
   (`1−(1−0.35)(1−0.25)(1−0.20)(1−0.20)`, see migration 021 header) caps strong
   signals; the NFR-4 gate passes by 0.0063 — one threshold nudge flips it.
3. **ECE 0.1994**: 10-bin calibration error is high; probabilities are
   over/under-confident despite passing the Brier gate.
4. **Fallback copy-paste risk**: `DEFAULT_BENCHMARK_REPORT` static payload in
   `evaluation_router.py` can mask a missing/unreadable
   `test-results/benchmark_evaluation_report.json` — a green endpoint with stale data.
5. **Echo exclusion correctness**: `DISPATCHER_APPROVAL` rows excluded as
   `excluded_echoes` before the `missing_pred` check; a mislabeled
   `verification_source` silently shrinks live N.
6. **Proxy delay/4.0 circularity**: rows without stored forecast still derive
   `forecast_prob = clamp(predicted_delay_hours / 4.0, …)` — the delay proxy the
   stored-pred work was meant to retire (comment block in
   `outcome_evaluation_service.py` pre-`de078d7`).
7. **No `.pkl` model**: no serialized sklearn/calibration artifact exists in-repo;
   "calibrated" means formula-normalized, not fitted (Isotonic/Platt absent).
