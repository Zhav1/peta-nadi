## 2. Q4 — Human names

### 2.1 `frontend/lib/formatNode.ts` (new, ~130 lines)

| Export | Contract |
|---|---|
| `NodeDisplayInfo` | `{ name?, display_name?, kabupaten?, province?, type? }` — the minimum metadata every render site accepts |
| `prettyNodeSlug(id)` | `regency-159-indragiri-hilir` → `Indragiri Hilir`; `node-medan-amplas` → `Medan Amplas`; `pin-98.6722-3.5952` → `Titik 98.6722, 3.5952`; 3-letter acronyms preserved (`OKI`, `KNO`, `PLM`) |
| `formatNodeDisplay(info)` | `display_name \|\| name`, then appends `kabupaten` and `province` **only if not already contained** in the primary string — prevents `Tembilahan (Kab. Indragiri Hilir), Indragiri Hilir, Riau` |

| `formatNodeId(id, info?, customNodes?)` | Thin string wrapper: caller-resolved info wins, else resolve, else pretty slug |

Normalization reuses `normalizeRegencyId`, so display and lookup can never disagree about the index.

### 2.3 Backend gazetteer merge (not overwrite)

`fetchGazetteerNodes()` maps every backend node through `mergeBackendGazetteerNode(node)`:

1. Normalize the backend `id`/`name` to a slug.
2. Find the matching local `PAN_SUMATRA_GAZETTEER` entry (`name`, `display_name`, `slug`, `node-<slug>`, `regency-<slug>`).
3. **Local richness wins for missing fields:** keep the backend's authoritative `lat`/`lon` when numeric, but backfill `display_name`, `kabupaten`, `kecamatan`, `province`, `corridor`, `type` from the local entry.
4. No match → pass through with `display_name: node.name` and `type: 'regency'` (still never raw).

This is intentionally a *merge*, not a rewrite of the backend response: the moment `/geocode/nodes` ships `display_name`/`kabupaten`, the local values stop being used without any frontend change.

## 3. Q5 — Legend, provenance, toggles

### 3.1 Legend (`DashboardClient.FloatingMapLegend`)

New block, separated by a divider:

- Heading `KORIDOR LANGSUNG VS RING PULAU` + amber badge `SIMULASI/OFFLINE`.
- Emerald solid swatch → `Darat Langsung (disorot)` / "Garis penuh emerald: rute darat bebas bahaya."
- Sky dashed swatch → `Laut — Ring Pulau`.
- Cyan dashed swatch → `Udara — Ring Pulau`.
- Footnote: `Badge SIMULASI/OFFLINE menandai geometri interpolasi (garis lurus), bukan rute jalan raya live.`
- `Visibilitas Koridor` grid: `Darat` / `Laut` / `Udara` buttons, each `aria-pressed` + `ON`/`OFF`, plus `Semua ON` reset.

### 3.2 Provenance badge in the simulator bar

`hasOfflineCorridors = activeCorridors.some(r => /SIMULASI\/OFFLINE/i.test(r.description))`:

- any offline → amber `SIMULASI/OFFLINE` (tooltip: "Geometri hasil interpolasi garis lurus, bukan jalan raya live")
- all live → emerald `LIVE` (tooltip: "Geometri rute live dari Mapbox Directions")
- no corridors → no badge (no fabricated provenance)

The label is derived from the route payload written by `aiDynamicRouter` (`summary: 'SIMULASI/OFFLINE: garis lurus, bukan geometri jalan live'`, line 999; description prefix at line 1580) — the UI never decides on its own that a line is live.

### 3.3 Map rendering

- `CrisisMap` route layer stroke becomes a data-driven case: direct-land lines **6.5 px**, island-ring legs **5 px** (`line-width: ['case', ['==', ['get','isDirectLand'], true], 6.5, 5]`).
- Every route/leg feature now carries `corridorClass: 'land' | 'sea' | 'air'`, `isDirectLand`, `isIslandRing`.
- `isCorridorVisible(route, idx)` filters by `corridor_type`: `land_primary`/`land_detour`/`hold_staging` → land toggle, `sea_intermodal` → sea, `air_intermodal` → air; `viable === false` and `hiddenRouteIndices` still apply.
- When anything is hidden, the existing `Tampilkan Semua Rute` button also resets corridor visibility (`onResetCorridorVisibility`).

### 3.4 Why toggles instead of modality filtering

Q1's decision (always-show-all) means the operator sees land + sea + air simultaneously. Without toggles that reads as visual noise; with toggles it reads as a comparison tool. This is the resolution of the "modality ignored / sea always computed" complaint: nothing is hidden by default, and the operator chooses.

## 5. Risks / trade-offs

- **`mergeBackendGazetteerNode` is a heuristic matcher** (slug equality against five forms). A future backend node with a genuinely new name and no local entry passes through un-enriched rather than being dropped — degraded labels, never broken routing.
- **`prettyNodeSlug` title-cases**, so an all-caps local name becomes Title Case; acceptable for Indonesian place names, and always superseded by a real `display_name`.
- **The `SIMULASI/OFFLINE` badge is per-route-set, not per-polyline.** A mixed set (one offline, one live) shows the amber badge; the map stroke does not yet badge individual legs. Logged in Plan 06.
