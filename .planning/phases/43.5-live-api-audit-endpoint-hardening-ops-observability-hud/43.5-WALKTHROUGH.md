**Phase:** 43.5

## 1. Navigating to the Observability Console in the UI

1. Open the PreHub web application (`/dashboard`).
2. Click on the **EVALUASI** tab in the top navigation bar.
3. In the sub-navigation bar at the top of the Evaluation section, click **Diagnostik API & Observabilitas**.

---

## 2. Using the In-App API Diagnostics Tools

### A. Host Target Selection
- Click **Render Cloud** to probe `https://peta-nadi.onrender.com`.
- Click **Localhost:8000** to probe local development instances.
- Select **Custom URL** to test any custom staging or preview deployments.

### B. Running a Live Smoke Test
- Click the **[ Uji Semua API ]** button.
- Watch the live progress as endpoints transition from `PROBE` to `200 OK` (Green badge) or `FAIL` (Red badge) with round-trip latency in milliseconds.
- Inspect the summary cards at the top: Target Host, Tingkat Keberhasilan (Pass Rate %), Rata-rata Latensi (Avg Latency ms), and Last Sync Timestamp.

### C. Filtering Endpoints
- Type in the **Cari endpoint...** search bar to quickly filter endpoints by name, URL path, or category.
- Use the **Kategori** dropdown to isolate specific functional groups (`System`, `Incidents`, `Commodities`, `News`, `Corridor`, `Fleet`, `Auth`, `Evaluation`).

### D. Inspecting Background Worker Logs
- View the real-time event wire showing heartbeat pings from `_poll_bmkg_loop`, `_poll_tomtom_loop`, `_poll_news_loop`, and `fleet_service`.
- Filter logs by severity using the level buttons: `ALL`, `INFO`, `WARN`, `ERROR`.

---

## 3. Running the CLI Audit Tool from Terminal

To run the automated audit tool from the command line:

```powershell
# Probe Render Cloud backend
& "backend/.venv/Scripts/python.exe" scripts/audit_backend_apis.py --url https://peta-nadi.onrender.com

# Probe Localhost backend
& "backend/.venv/Scripts/python.exe" scripts/audit_backend_apis.py --url http://localhost:8000
```

The output report will be automatically saved as JSON at `test-results/live_api_audit_report.json`.
