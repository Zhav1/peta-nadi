# Plan 43.5-01: Live API Audit, Endpoint Hardening & Ops Observability Console

## Goal
Conduct a comprehensive live network audit against the deployed Render backend (`https://peta-nadi.onrender.com`), resolve endpoint contract gaps, and build a native, minimalist System Observability & API Diagnostics console into the PreHub frontend without third-party container bloat.

## Deliverables
1. **Automated CLI API Audit & Diagnostic Probe Tool (`scripts/audit_backend_apis.py`)**:
   - Asynchronous probe across all 28 REST & WebSocket endpoints.
   - Latency measurement, HTTP status code validation, JSON schema structure verification.
   - Target host switching (`--url https://peta-nadi.onrender.com` vs `--url http://localhost:8000`).
2. **Backend Route Gap Resolution (`backend/app/routers/news_router.py`)**:
   - Implement `POST /api/v1/news/verify` handler with structured token overlap corroboration against authoritative RSS news feeds.
3. **Native Minimalist Observability UI (`frontend/components/dashboard/SystemObservabilitySection.tsx`)**:
   - Integrated into `EvaluationSection.tsx` under sub-tab `Diagnostik API & Observabilitas`.
   - Host target switcher (`Render Cloud`, `Localhost:8000`, `Custom URL`).
   - 1-click `[ Uji Semua API ]` smoke test runner.
   - Real-time endpoint health matrix with search & category filters.
   - Data source adapter monitor (BMKG, TomTom, OpenSky, AISstream, Antara, Supabase).
   - Live background worker log terminal (`ALL`, `INFO`, `WARN`, `ERROR`).
   - Strict minimalist ergonomics: zero emojis, 100% monochrome Lucide SVG icons, glassmorphic dark theme.

## Verification Criteria
- [x] CLI audit script tests all 28 endpoints and saves diagnostic report.
- [x] `POST /api/v1/news/verify` returns structured corroboration and passes unit tests.
- [x] Next.js frontend builds cleanly (`npm run build`) with zero type or lint errors.
- [x] Pytest backend suite passes 100% (108/108 tests).
- [x] Code pushed to GitHub repository to trigger Render redeployment.
