# Plan 61-01: Render CORS and Berita Audit Remediation

## Goal
Resolve systemic cross-origin, news pipeline, and demo engine failures between the deployed Vercel frontend (`https://pre-hub.vercel.app`) and the Render backend (`https://peta-nadi.onrender.com`), ensuring all 26 REST API Evaluator endpoints pass and the left sidebar actively populates verified news.

## Proposed Changes

### 1. Backend CORS, Root Route & Server Bug Fixes
- **`backend/app/config.py`**: Add `https://pre-hub.vercel.app` and `https://peta-nadi.onrender.com` to `cors_origins`.
- **`backend/app/main.py`**:
  - Broaden `allow_origin_regex` to `r"https?://((localhost|127\.0\.0\.1)(:\d+)?|.*\.vercel\.app|.*\.onrender\.com)"`.
  - Add `GET /` root endpoint returning JSON health & docs link.
- **`render.yaml`**: Update `CORS_ORIGINS` to include Vercel origins.
- **`backend/Dockerfile`**: Add `COPY data/ ./data/` to provide fixtures and synthetic data inside the Docker container.
- **`backend/app/routers/demo_router.py`**:
  - Implement `_find_data_file` multi-path resolution (`backend/data`, `../data`, CWD).
  - Provide an inline crisis state fallback if file is missing to guarantee `POST /api/demo/start` returns `200 OK`.
- **`backend/app/routers/news_router.py`**:
  - Guard `background_tasks.add_task` with `if background_tasks is not None: ... else: asyncio.create_task(...)`.
  - Validate `req.approval_id` with `uuid.UUID(str(...))` raising `HTTPException(422)` on invalid format.

### 2. Frontend Next.js Proxy, Berita Sidebar & API Evaluator Resilience
- **`frontend/app/api/proxy/[...path]/route.ts`**: Create dynamic server-side proxy route forwarding requests to Render backend.
- **`frontend/lib/api.ts`**: Intelligent `getBaseUrl()` host detection and auto-fallback to `/api/proxy` upon CORS `TypeError: Failed to fetch`.
- **`frontend/hooks/useNewsVerification.ts`**: Replace `Promise.all` with `Promise.allSettled` and provide verified Sumatra baseline fallback.
- **`frontend/components/dashboard/DashboardClient.tsx`**: Rename floating collapsed toggle button from `SIDEBAR` to `BERITA`.
- **`frontend/components/dashboard/SystemObservabilitySection.tsx`**: Add automatic `/api/proxy` fallback in `runSingleProbe`.

### 3. Automated Test Suite
- **`backend/tests/test_audit_fixes.py`**: Add 5 comprehensive tests verifying `GET /`, CORS preflight, `POST /api/demo/start`, `get_live_news(None)`, and `hitl-action` UUID validation.
