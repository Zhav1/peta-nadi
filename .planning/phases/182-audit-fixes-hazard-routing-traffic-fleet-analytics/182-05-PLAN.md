# Slice 182-05: Laporan Recharts Loop Prevention & North Sumatra Province Boundary Framing

## Goal
Mengeliminasi potensi crash Redux Recharts Error #185 di tab Laporan via konstanta prop hoisting, serta memperbaiki bounding box/kamera saat memfokuskan Provinsi Sumatera Utara (Sumut) agar mencakup seluruh 33 kabupaten/kota dan bukan hanya Kota Medan.

## Target Files
- `frontend/components/dashboard/LaporanCharts.tsx`
- `frontend/components/dashboard/DashboardClient.tsx`
- `backend/app/nlp/geocoding_service.py`

## Tasks
1. Di `frontend/components/dashboard/LaporanCharts.tsx`:
   - Hoist semua inline object/array/element props pada `BarChart` dan `ComposedChart`:
     `margin={{ ... }}`, `tick={{ ... }}`, `axisLine={{ ... }}`, `content={<ChartTooltip />} `, `cursor={{ ... }}`, `dot={{ ... }}`, `activeDot={{ ... }}` menjadi konstanta level modul:
     `LAPORAN_CHART_MARGIN`, `X_TICK`, `X_AXIS_LINE`, `Y_TICK`, `TOOLTIP_CURSOR_BAR`, `TOOLTIP_CURSOR_LINE`, `LINE_DOT`, `ACTIVE_DOT`, `CHART_TOOLTIP_CONTENT = <ChartTooltip />`.
     Ini menghentikan siklus re-render tak hingga Recharts 3.9.2 persis seperti yang telah diterapkan di `PriceTrendChart.tsx`.
2. Di `frontend/components/dashboard/DashboardClient.tsx`:
   - Di array `SUMATRA_LOCATION_FALLBACK_MAP`:
     Pisahkan entri `medan` dengan `sumatera utara`/`sumut`:
     - `{ keywords: ['medan'], coords: [98.6722, 3.5952], zoom: 11.5 }` (tetap level kota/arteri).
     - `{ keywords: ['sumatera utara', 'sumut'], coords: [99.0722, 2.7052], zoom: 7.8 }` (mencakup seluruh provinsi dari Langkat sampai Nias/Mandailing Natal).
3. Di `backend/app/nlp/geocoding_service.py`:
   - Pada `PROVINCE_CENTROIDS`: Ubah centroid `"Sumatera Utara"` dari titik Kota Medan `(3.5952, 98.6722)` menjadi titik tengah geografis wilayah Sumatera Utara yang representatif: `(2.7000, 99.0700)` (sekitar Danau Toba / Pematang Siantar) agar kalkulasi spasial tidak bias ke Medan.
