# Slice 182-03: Alternative Route De-emphasis & Settlement Deep-Link Hydration

## Goal
Menghilangkan kesan duplikasi rute kembar dengan menerapkan de-emphasis visual standar industri pada rute alternatif (warna abu-abu netral teredam), serta memperbaiki parser deep-link untuk koordinat pemukiman/settlement.

## Target Files
- `frontend/components/map/CrisisMap.tsx`
- `frontend/components/dashboard/DashboardClient.tsx`

## Tasks
1. Di `frontend/components/map/CrisisMap.tsx`:
   - Pada layer `route-paths-alternative`:
     - Ganti warna default garis alternatif dari hijau terang `#34D399` menjadi warna slate netral teredam: `'#64748b'` (Slate-500) dengan `line-opacity: 0.55` dan `line-width: 3.5`.
     - Pertahankan garis putus-putus `[2, 2]`.
     - Dengan demikian, rute utama aktif (`#10B981`, width 6px) menjadi fokus visual tunggal, dan rute alternatif tidak tampak bertabrakan atau menduplikasi jalan.
2. Di `frontend/components/dashboard/DashboardClient.tsx`:
   - Di fungsi `resolveNodeInfo`:
     - Tambahkan pencocokan regex untuk ID berpola `settlement-<lon>-<lat>` dan `pin-<lon>-<lat>`:
       Jika node ID diawali `settlement-` atau `pin-`, parse koordinat lon/lat dari string tersebut dan kembalikan objek node valid `{ id, name: 'Titik Peta / Pemukiman', coords: [lon, lat], type: 'settlement' }`.
     - Ini memastikan URL deep-link dengan settlement origin/dest dapat direhidrasi secara mulus saat browser di-refresh.
