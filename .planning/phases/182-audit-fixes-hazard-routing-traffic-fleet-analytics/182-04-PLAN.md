# Slice 182-04: Maritime Vessel Rendering LOD & Sensor Metric Honesty

## Goal
Memastikan kapal maritim di Selat Malaka tetap terlihat pada tingkat zoom pulau, memberikan status penjelasan yang jelas saat armada perusahaan kosong di mode tamu, dan memperjelas tooltip metrik cuaca/titik panas.

## Target Files
- `frontend/lib/mapDataPaint.ts`
- `frontend/components/fleet/TenantFleetRoster.tsx`
- `frontend/components/dashboard/TopNavTelemetry.tsx`

## Tasks
1. Di `frontend/lib/mapDataPaint.ts`:
   - Pada `FLEET_DOTS_PAINT`, ubah kurva interpolasi `circle-opacity`:
     Dari batas bawah `3.2 -> 0.0` menjadi `2.4 -> 0.0` dan `3.2 -> 0.9` (dan `4.0 -> 1.0`).
     Ini memastikan 500 unit kapal maritim di Selat Malaka tidak lenyap/transparan saat pengguna melihat peta pada skala makro Sumatera.
   - Tambahkan sedikit `circle-stroke-width: 1` dengan `circle-stroke-color: 'rgba(255, 255, 255, 0.4)'` agar titik teal kapal kontras terhadap basemap gelap laut.
2. Di `frontend/components/fleet/TenantFleetRoster.tsx`:
   - Pada kondisi `scopedVehicles.length === 0`:
     - Tampilkan pesan informatif:
       `"Armada Perusahaan: 0 Unit. Masuk sebagai Dispatcher berlisensi untuk mendaftarkan dan memantau armada privat Anda."`
3. Di `frontend/components/dashboard/TopNavTelemetry.tsx`:
   - Sempurnakan tooltip counter sensor:
     - `Cuaca 0`: `"Gangguan Ekstrem: 0 (Aman - Tidak ada bencana banjir/badai aktif)"`
     - `Waspada Dini 10`: `"Peringatan Dini Cuaca BMKG: 10 Wilayah"`
     - `Titik Panas 0`: `"Satelit NASA FIRMS: 0 Kebakaran (Terverifikasi Bersih)"`
