# Phase 46 Plan 01: Forensic AI-Slop Audit & "The Strategic Sentinel" Design Contract

## Objective
Conduct an unsparing, full-scale forensic audit of the PreHub Next.js frontend across landing and dashboard routes to quantify AI-generated visual clutter, component slop, information overload, and design system drift. Codify the target design contract in `DESIGN.md` ("The Strategic Sentinel").

---

## Scope of Audit
1. **Landing Page (`/`):**
   - Hero section, scroll video/canvas sequence, feature showcases, kinetic grid, live telemetry showcase, and footer.
   - Audit for duplicate components, repetitive cards, scanlines, and floating kicker chips.
2. **Operations Dashboard (`/dashboard`):**
   - Top telemetry bar (`TopNavTelemetry.tsx`, `AgentStatusWidget.tsx`).
   - Left OSINT sidebar and drawer triggers.
   - Right docked drawer (`CrisisSidebar.tsx`, `MitigationTab.tsx`, `EvidenceTab.tsx`, `EconomicTab.tsx`, `SpoilageHedgingCard.tsx`, `ComplianceInspectorCard.tsx`).
   - Map controls, time horizon bottom bar, legends, and vehicle markers (`CrisisMap.tsx`, `FleetVehicleLayer.tsx`, `TargetLockReticle.tsx`).
   - Split views: Analytics, Simulation, Reports, and Evaluation.
3. **Modals & Overlays:**
   - `AuthModal.tsx`, `FleetOnboardingModal.tsx`, `GuidedDemoPanel.tsx`, `Toast.tsx`.

---

## Execution Tasks

- [x] **Task 1: Automated & Visual Forensic Scan**
  - Run regex pattern analysis scripts across all TSX files in `frontend/` to count `backdrop-blur`, custom glow shadows, sub-12px microtext, gradients, and arbitrary rounded corners.
  - Capture rendered screenshots of every route and tab at 1440x900 using Playwright.
  - Document each finding with Element Location, Problem, Slop Rationale, Severity, and Recommended Action.

- [x] **Task 2: Compile Formal Audit Report**
  - Write `slop_audit_report.md` detailing the 6 forensic pillars: Visual Overload, Component Slop, Information Slop, Design System Drift, Layout Rigidity, and Second-Order AI Genericness.

- [x] **Task 3: Author "The Strategic Sentinel" Design Contract**
  - Write `DESIGN.md` establishing color tokens, elevated surface hierarchy, 12px typographic floor, architectural button specs, and strict prohibition of generic AI gradients and glassmorphism.
  - Export machine-readable design tokens into `.impeccable/design.json`.

---

## Verification Criteria
- [x] Audit report catalogs exact line numbers and component files without generic approximations.
- [x] Design contract provides unambiguous drop-in Tailwind classes for surfaces, typography, borders, and buttons.
- [x] Zero code modifications during the audit phase to prevent premature or half-baked refactoring.
