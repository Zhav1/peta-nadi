## Visual Hierarchy & Focal Point

### 1. Primary Focal Point
**Target-Locking Reticle Crosshair with Bracket Corners on Mapbox WebGL Canvas.**
- When an asset is selected, the eye is immediately drawn to four high-contrast cyan corner brackets (`#00f0ff`) framing the target at a 32px bounding radius.
- The reticle features micro crosshair ticks and dynamic orientation aligning with the asset's heading azimuth.
- An animated subtle breathing pulse (scale 1.0 to 1.05 over 1.5s) indicates an active telemetry lock.

### 2. Secondary Focal Point
**Tactical Monospaced Telemetry HUD Console (Floating Top-Left).**
- Positioned at `top-20 left-4` with glassmorphic styling: `backdrop-blur-md bg-[#0c0e12]/80 border border-white/10`.
- Immediate scan priority:
  1. Callsign & Transponder ID (Heading 16px, 600 weight, `#ffffff`).
  2. Kinematic Metrics Grid (Display 22px speed callout, Body 13px COG/Heading/Altitude).
  3. Cargo & Cold-Chain Telemetry (13px, temperature pill with normal `#34d399` vs warning `#ffb950`).
  4. Follow-Camera Control Button ("Aktifkan Kamera Pengikut" with Lucide `Video` / `Compass` icon, `cursor-pointer`).

### 3. Tertiary Focal Point
**Dynamic Bearing Vectors & Breadcrumb Trails.**
- Directional velocity vectors projecting forward from assets as dashed cyan/modality lines scaled to speed ($L = v \times \text{scale}$).
- Trailing breadcrumb points rendered at low opacity (`rgba(255,255,255,0.15)`) showing the last 10 historical telemetry positions.
- Modality filter pills floating top-right allowing instant isolation of Truck, Maritime, or Air units.

## Component Inventory & Interaction Contracts

### 1. Native WebGL Fleet Asset Layer (`FleetVehicleLayer.tsx`)
- **Rendering Mechanism:** 100% Mapbox WebGL Native Layer (`symbol` and `line` layers via GeoJSON sources). Zero DOM HTML marker thrashing (`mapboxgl.Marker` completely eliminated).
- **Target Performance:** Sustained 60 FPS under 100+ active assets with map rotation, pitch (0°-60°), and continuous zoom.
- **WebGL Sources:**
  - `fleet-telemetry-points`: GeoJSON `FeatureCollection<Point>` with properties `{ id, modality, heading, speed_kmh, status, is_selected }`.
  - `fleet-bearing-vectors`: GeoJSON `FeatureCollection<LineString>` with calculated forward vectors based on bearing and velocity.
  - `fleet-breadcrumb-trails`: GeoJSON `FeatureCollection<LineString>` representing historical trajectory polylines.
- **Click Interaction:** Clicking any asset invokes Mapbox queryRenderedFeatures, triggers camera easing, locks target reticle, and opens Tactical HUD Console.

### 2. Tactical Target Lock Reticle
- **Geometry:** 4 bracket corners (10px length, 2px stroke, `#00f0ff`), center circular pip (3px dot), 4 cardinal ticks (4px length).
- **Behavior:**
  - Position is locked to the vehicle's dynamic coordinates across every animation frame.
  - Smooth entrance: Scales from 48px to 32px with fade-in over 200ms cubic-bezier(0.16, 1, 0.3, 1).
  - Dismissal: Clicking map canvas or clicking "Lepas Kunci Target" disengages reticle with 150ms fade-out.

### 3. God's-Eye Follow Camera Mode
- **Controller:** Toggle button inside HUD Console: "Aktifkan Kamera Pengikut" (`cursor-pointer`).
- **Active State:** Button shifts from neutral `bg-[#1e2024] text-slate-300` to tactical active `bg-cyan-950/80 text-cyan-300 border-cyan-400`. Label updates to "Kamera Pengikut Aktif".
- **Camera Mechanics:**
  - Mapbox `easeTo` or continuous frame synchronization centering target coordinates `[lng, lat]` while preserving user zoom level (clamped min zoom 8.5) and pitch angle (clamped 30°-45° for tactical 3D god's-eye perspective).
  - Smooth pan transition damping (150ms interpolation).
  - Manual map drag/pan by user immediately disengages follow-camera mode to prevent input fighting, reverting button to "Aktifkan Kamera Pengikut".

### 4. Monospaced Tactical Telemetry Card
- **Layout Structure:**
  ```
  +-------------------------------------------------------------+
  | [MODALITY ICON] CALLSIGN / ASSET NAME           [X TUTUP]   |
  | ID: MMSI / ICAO24 / VIN | STATUS: AIS AKTIF / GPS LOCK      |
  +-------------------------------------------------------------+
  | KINEMATIKA:                                                 |
  |   KECEPATAN: 24.5 kts (45.4 km/j)   HEADING: 142° SE       |
  |   ELEVASI/DRAUGHT: 7.2 m            LAT/LON: 3.792N 98.678E |
  +-------------------------------------------------------------+
  | KARGO STRATEGIS:                                            |
  |   KOMODITAS: 1.800 Ton Beras BULOG                          |
  |   RANTAI DINGIN: 2.8°C [NORMAL]                             |
  +-------------------------------------------------------------+
  | RUTE: ASAL -> TUJUAN (ETA: 4j 15m)                          |
  | LATENSI SINYAL: 1.2s lalu [LIVE PING]                       |
  +-------------------------------------------------------------+
  | [BUTTON: AKTIFKAN KAMERA PENGIKUT]                          |
  +-------------------------------------------------------------+
  ```
- **Styling Rules:**
  - `backdrop-blur-md bg-[#0c0e12]/80 border border-white/10 shadow-2xl rounded-xl`.
  - All numeric telemetry values rendered in `font-mono` at 13px/400.
  - Temperature pill: `bg-emerald-950/60 text-emerald-400 border-emerald-500/30` when `<= 4.0°C`; switches to `bg-amber-950/60 text-amber-400 border-amber-500/30` with warning label `[PERINGATAN SUHU]` when `> 4.0°C`.
  - Buttons MUST have `cursor-pointer` class and smooth transition (`transition-all duration-200`).
