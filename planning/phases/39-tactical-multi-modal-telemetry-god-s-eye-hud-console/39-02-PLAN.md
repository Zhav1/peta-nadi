  <action>
    1. In `frontend/lib/geoUtils.ts`:
       - Export `projectBearingEndpoint(startLngLat: [number, number], bearingDeg: number, speedKmh: number, scaleHours: number = 0.05): [number, number]`:
         - Uses true spherical geodesy equations:
           $\delta = d / R$ where $R = 6371.0\text{ km}$, $d = \max(0.5, \text{speedKmh} \times \text{scaleHours})$.
           $\theta = \text{bearingDeg} \times \pi / 180$.
           $\phi_1 = \text{lat}_0 \times \pi / 180$, $\lambda_1 = \text{lon}_0 \times \pi / 180$.
           $\phi_2 = \arcsin(\sin\phi_1 \cos\delta + \cos\phi_1 \sin\delta \cos\theta)$.
           $\lambda_2 = \lambda_1 + \text{atan2}(\sin\theta \sin\delta \cos\phi_1, \cos\delta - \sin\phi_1 \sin\phi_2)$.
           Returns `[lon2, lat2]`.
    2. In `FleetVehicleLayer.tsx`:
       - Add GeoJSON source `fleet-bearing-vectors`: `FeatureCollection<LineString>`.
       - Add layer `fleet-bearing-vectors-layer`: type `line`, paint `{ 'line-color': ['get', 'color'], 'line-width': 1.5, 'line-dasharray': [2, 2] }`.
       - In animation loop, calculate forward projected LineString $(P_0 \to P_{\text{end}})$ for each moving vehicle using `projectBearingEndpoint()` and update `source.setData()`.
    3. Create `frontend/components/map/TargetLockReticle.tsx`:
       - Accepts props: `map: mapboxgl.Map | null`, `targetLngLat: [number, number] | null`, `callsign: string`, `onDismiss: () => void`.
       - Uses `map.project(targetLngLat)` to compute pixel coordinates `(x, y)`.
       - Updates `containerRef.current.style.transform = translate3d(${x - 32}px, ${y - 32}px, 0)` on `map.on('move')` and `requestAnimationFrame`.
       - Renders 64x64 SVG overlay with:
         - 4 corner brackets (10px length, 2px stroke in `#00f0ff`, `strokeLinecap="round"`).
         - Center target pip (circle radius 2.5px in `#00f0ff`).
         - 4 cardinal tick marks.
         - CSS breathing pulse animation (scale 1.0 to 1.05 over 1.5s ease-in-out infinite).
         - Callsign lock badge positioned below reticle: `bg-[#0c0e12]/90 border border-cyan-500/40 text-[9px] font-mono text-cyan-300 px-1.5 py-0.5 rounded shadow-lg`.
  </action>
