## Context & Architectural Grounding

- **Real Logistics Grounding:** In line with user requirements (*"make it as real as possible with no mockup data"*), the manual must not use generic or hypothetical placeholders. All operating procedures must reference real Sumatra infrastructure (Jalinsum, Tol Trans-Sumatra MKTT and Bakauheni–Terbanggi Besar, Pelabuhan Belawan, Bakauheni–Merak Ro-Ro ferry, Sitinjau Lauik mountain pass), official agencies (BKHIT, BPJT, Satgas Pangan, Dishub, BMKG, Antara), and implemented UI components.
- **Strict Minimalist Ergonomics (NFR-11):** The documentation and all referenced interface workflows adhere strictly to NFR-11 (Zero emojis, zero boastful marketing claims, 100% monochrome Lucide SVG icons, functional labels, and high-contrast dark theme).
- **Test Inventory Reconciliation:** With Phase 43 (`test_fleet_ingest.py`: 9 tests), Phase 44 (`test_intermodal_hedging_compliance.py`: 17 tests), and Phase 45 (`test_pilot_e2e.py`: 8 tests), the automated verification suite scales from 103 to 133 passing tests with 100% pass rate in <50 seconds.
