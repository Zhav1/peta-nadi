# Plan 45-01: Automated E2E Pilot Test Suite & Multi-Container Docker Packaging

## Objective

Deliver the definitive automated pilot verification test suite and production container deployment topology for Milestone M3, covering decisions D-01, D-02, D-03, and D-04:
1. Harden backend health check routing (`/api/v1/health`) and SQLite connection concurrency (`PRAGMA journal_mode=WAL; PRAGMA busy_timeout=5000;`) per D-03 and D-04.
2. Implement 3 end-to-end operational pilot drills in `backend/tests/test_pilot_e2e.py` per D-01 using 100% real Pan-Sumatra logistics data (0% synthetic dummy data per D-02):
   - **Drill 1 (D-01, D-02):** Belawan $\to$ Pekanbaru ultra-perishable *Cabai Merah Keriting* spoilage hedging detour around Tebing Tinggi flood.
   - **Drill 2 (D-01, D-02):** Bakauheni Ferry Strait Crossing cold-chain beef transit with non-negotiable BKHIT quarantine hard block and release.
   - **Drill 3 (D-01, D-02):** Padang $\to$ Solok via Sitinjau Lauik Class III mountain pass with MST axle-load warning and operator liability override.
3. Harden multi-stage Next.js standalone container packaging (`frontend/Dockerfile`) on `node:20-alpine` per D-03.
4. Standardize production multi-container orchestration (`docker-compose.yml`), dev overrides (`docker-compose.override.yml`), and environment definitions (`.env.example`) with health checks per D-03 and D-04.

---

## Context & Architectural Grounding

- **Real Data Policy:** Per explicit user directive (*"make it as real as possible with no mockup data"*), every scenario coordinate, road segment, toll tariff, fuel price, commodity metric, license plate, and gateway name throughout `test_pilot_e2e.py` must match ground-truth Pan-Sumatra logistics data:
  - 54-node NetworkX road cache (`data/road_network_sumatra.json`).
  - 18 Pan-Sumatra strategic gateways (`backend/app/services/intermodal_sync_service.py`).
  - Official BPJT Trans-Sumatra toll tariffs for Golongan I through Golongan V vehicles.
  - Pertamina base fuel rates (Biosolar IDR 6,800/L, Dexlite IDR 14,550/L, Pertamina Dex IDR 15,100/L).
  - Real PIHPS commodity items and LKBN ANTARA news feeds.
- **Docker Compose Topology:** The production orchestration separates concerns into `prehub-redis` (`redis:7-alpine`), `prehub-backend` (FastAPI with 2 Uvicorn workers), and `prehub-frontend` (Next.js 14 standalone). Container health checks verify readiness, and named persistent volumes ensure zero data loss during restarts.

---

## Threat Model & Security Controls

| Threat ID | Threat Vector | Mitigation Strategy | Verification Invariant |
|:---|:---|:---|:---|
| **T-45-01** | Concurrent SQLite write locking under multi-worker Uvicorn (`--workers 2`) | Configure WAL journal mode and 5000ms busy timeout in `get_db_connection()` | No `sqlite3.OperationalError: database is locked` during concurrent writes |
| **T-45-02** | Quarantine bypass on inter-island livestock cargo | Non-negotiable `HARD_BLOCK` enforced in `compliance_service.py` when BKHIT certificate is absent | `overall_status == "HARD_BLOCK"` and `can_dispatch is False` |
| **T-45-03** | Unauthorized or unrecorded MST axle-load override on secondary roads | Model validator in `DecisionTraceCreate` requires mandatory `notes` when `action == "OVERRIDE"` | HTTP 422 / `ValueError` when `notes` is empty; audit logged in SQLite |
| **T-45-04** | Container startup flapping and race condition on unhealthy dependencies | Implement Docker Compose healthchecks with explicit `start_period` and `condition: service_healthy` | Containers wait until upstream services are ready before handling traffic |
