# Plan 44-03: Post-Phase-42 & Phase 44 Plothole, Variable Consistency & Compliance Audit

**Phase:** 44  
**Plan:** 44-03  
**Goal:** Conduct an exhaustive consistency audit across backend services, schemas, route handlers, and frontend components introduced from Phase 42 through Phase 44. Eliminate regulatory edge-case bugs (false-positive BKHIT quarantine blocks), resolve variable name mismatches, dynamic route parameter passing, hook reactive dependencies, and webhook endpoint ports.

---

## 1. Context, Environment & Constraints

### Environment Conditions
- **Operating System:** Windows 11 (PowerShell)
- **CLI Token Optimization:** All terminal commands routed via `rtk` (Rust Token Killer) CLI proxy to minimize token waste.
- **Python Runtime:** Python virtual environment executed strictly via `backend\.venv\Scripts\python.exe`.
- **Database / Auth:** Supabase Auth & Multi-Role RBAC (`DISPATCHER`, `REGULATOR`, `GUEST`) with local SQLite fallback.
- **Design System Guarantees:**
  - Non-AI Anti-Patterns: Zero emojis in UI or docs (100% monochrome Lucide SVG icons).
  - No generic pink/purple AI gradients.
  - Consistent Glassmorphism: `backdrop-blur-md bg-[#0c0e12]/80 border border-white/10`.
  - Explicit `cursor-pointer` on all interactive triggers.

### Architectural Invariants
1. **BKHIT Quarantine Rule (UU No. 21/2019):** Applies strictly to inter-island agricultural transit (Sumatra $\leftrightarrow$ Java or other islands). Shipments remaining within mainland Sumatra (even if originating/terminating in Bakauheni) are exempt from BKHIT quarantine hard blocks.
2. **MST Axle-Load Rule (UU No. 22/2009 & Permenhub 60/2019):** Class III roads (collector/mountain corridors like Malalak, Sitinjau Lauik, Tarutung) enforce an 8.0-Ton Muatan Sumbu Terberat limit. Heavy cargo trucks (>8 Ton) traversing these corridors must trigger a tactical advisory warning.
3. **Traceability Invariant:** Operator approvals must reflect the active authenticated session persona (`user.name` / `user.email` / `user.id`), not hardcoded placeholders.

## 2. Issues Discovered

1. **False-Positive BKHIT Quarantine Block (`compliance_service.py`):**
   - Standalone keyword `"bakauheni"` in `ferry_cues` caused intra-Sumatra shipments (e.g. Bakauheni $\to$ Palembang) to trigger a `HARD_BLOCK`.
2. **Commodity Variable Mismatch (`MitigationTab.tsx`):**
   - Frontend checked `(crisis as any).commodities_affected[0]`, which does not exist on `CrisisState`. Actual field is `crisis.inflation_forecast?.commodity`, causing the hedging matrix to always default to `'Cabai Merah Keriting'`.
3. **Route Origin/Destination Parsing Failure (`MitigationTab.tsx`):**
   - Route names use `"Rute Utama (Jalan Tol / Jalinsum)"` without `'→'`. `split('→')[0]` returned the entire description as origin.
4. **Hardcoded Traversed Roads & MST Warning Bypass (`MitigationTab.tsx`):**
   - `ComplianceInspectorCard` was passed hardcoded `traversedRoads=['Jalan Tol Medan - Tebing Tinggi', 'Lintas Timur Sumatera']`, preventing MST warnings even when an operator selected a detour via Class III mountain roads (e.g. Malalak).
5. **Hardcoded Operator ID (`MitigationTab.tsx`):**
   - Approvals submitted `operator_id: 'OP-CHIEF-01'` instead of the active user session from `useAuth()`.
6. **Missing Hook Dependency (`ComplianceInspectorCard.tsx`):**
   - `useEffect` omitted `traversedRoads` and `commodity`, causing inspection status to remain stale when switching routes.
7. **TMS Webhook Port Mismatch (`FleetOnboardingModal.tsx`):**
   - Generated URL used `window.location.origin` (port 3000 Next.js) rather than FastAPI backend (port 8000).
